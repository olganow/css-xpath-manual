### Как тестировать:
1. Скачайте [страницу 'Меню "Сладкая Булочка"'](index.html)  на компьютер и откройте ее в браузере.

2. Откройте консоль браузера (Devtools → Elements):
    Cmnd + F - посмотрите расположение элемента

3. Откройте консоль браузера (Devtools → Console):

- // для CSS 
```javascript
   document.querySelectorAll('.item')
```
 ```javascript
   document.querySelector('#item-3')
```
-  // для XPath
```javascript
   $x("//div[@class='item']")
```
```javascript
   $x("//span[text()='Булка с маслом']")
```
