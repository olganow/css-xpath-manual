## Интерактивная демонстрация
Демо-страница [index.html](index.html): - это меню кондитерской с разными элементами, 
на которой можно протестировать результаты поиска по CSS и XPath.

## Как тестировать:
1. Откройте [демо-страницу 'Меню "Сладкая Булочка"'] (https://img.shields.io/badge/version-2.3-green.svg)
   https://github.com/olganow/css-xpath-manual/index.html

2. Откройте консоль браузера (Devtools → Elements):
    Cmnd + F - посмотрите расположение элемента

3. Откройте консоль браузера (Devtools → Console):

- // CSS примеры
   document.querySelectorAll('.item')
   document.querySelector('#item-3')

-  // XPath примеры
   $x("//div[@class='item']")
   $x("//span[text()='Булка с маслом']")
