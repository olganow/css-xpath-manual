## 1. 🎯 Поиск по тегам и атрибутам


| **Описание** | **Что находит?** | **CSS селектор пример** | **XPath пример** | **Что найдёт в меню в html файле** |
|-------------|----------------|----------------------|----------------|-----------------------------------|
| Универсальные селектор | все элементы | * | //* | Все элементы страницы |
| Селекторы по тегу | элементы с соответствующим именем | div | //div | Все div элементы |
| Селекторы по ID | уникальный элемент с заданным идентификатором | #item-3 | //*[@id='item-3'] | "Сдобная булка с изюмом" |
| Селекторы по классу | Элементы с указанным классом | .promo-item | //*[@class='promo-item'] | Два акционных предложения |
| Селекторы по наличию атрибута | элементы, у которых этот атрибут присутствует | [data-promo] | //*[@data-promo] | Акционные блоки |
| Селекторы по началу значения атрибута | используются для частичного совпадения в начале строки | [class^="section-t"] | //*[starts-with(@class, 'section-t')] | Заголовки |
| Элемент у которого целое слово, отделенное пробелами | находят элементы, где test-3 является отдельным классом в списке, разделенном пробелами | [class~="test-3"] | //*[contains(@class, 'test-3')] | Элементы с классом содержащим test-3 |
| Элемент у которого часть строки promo-" | находят элементы, в атрибуте class которых содержится подстрока promo- | [class*="promo-"] | //*[contains(@class, 'promo-')] | Акционные блоки + раздел Акции дня |
| Элементы с ID, значение которых заканчивается на определённую подстроку | находят элементы, где значение атрибута id заканчивается на "form" | [id$="form"] | //*[ends-with(@id, 'form')] | Форма заказа |
| Элементы с точным набором слов названия класса | находят элементы, имеющие ровно эти два класса и никаких других | .item.special | //*[@class='item special'] | "Сдобная булка с изюмом" и "Горячий шоколад" |
| Элементы с атрибутом data-category | находят элементы при наличии у них указанного атрибута, независимо от его значения | [data-category] | //*[@data-category] | Товары и заголовки |
| Элементы с конкретным data-атрибутом | находят элементы, у которых значение атрибута data-category точно равно "bun" | [data-category="bun"] | //*[@data-category='bun'] | "Булка с маслом", "Булочка с корицей", "Круассан" |
| Элементы с **несколькими классами** одновременно | корректно находят элементы, которые одновременно имеют оба класса (test-1 и test-2) | .test-1.test-2 | //*[contains(@class, 'test-1') and contains(@class, 'test-2')] | Если у Вас День рождения |
| Элемент с атрибутом placeholder | находят поля ввода (input), у которых есть атрибут placeholder, независимо от его значения | input[placeholder] | //input[@placeholder] | Поля ввода с подсказками |
| Элемент **без определенного атрибута** | находят поля ввода (input), у которых полностью отсутствует атрибут required | input:not([required]) | //input[not(@required)] | Input без required |
| Элементы с **любым data-атрибутом** (начинающимся на data-) | корректно находят все элементы, у которых имя атрибута начинается с префикса data- | [data-] | //*[@*[starts-with(name(), 'data-')]] | Все элементы с data-атрибутами |

🎯 **Совет**: значение атрибута класса лучше заключать в одинарные кавычки 'form' чтобы избежать экранирования в IDE

- Селекторы по наличию атрибута `[data-promo]` и `//*[@data-promo]` находят элементы, у которых этот атрибут присутствует.
- **Элемент с атрибутом placeholder**: `input[placeholder]` и `//input[@placeholder]` корректно находят поля ввода (input), у которых есть атрибут placeholder, независимо от его значения.

## 📝 **2. Поиск по тексту элемента**

| **Что ищем?** | **Что находит?** | **CSS селектор пример** | **XPath пример** | **Что найдёт в меню в html файле** |
|--------------|----------------|----------------------|----------------|-----------------------------------|
| Элемент с точным текстом | находят элементы `<span>`, текстовое содержимое которых точно равно "Булка с маслом" | ❌ | //span[text()='Булка с маслом'] | Название "Булка с маслом" |
| Элементы, содержащие подстроку в тексте | находят любые элементы, в тексте которых содержится подстрока "булка" | ❌ | //*[contains(text(), 'булка')] | Все элементы со словом "булка" |
| Элементы, текст которых начинается с определённой подстроки | корректно находят любые элементы, текстовое содержимое которых начинается с подстроки "Бул" | ❌ | //*[starts-with(text(), 'Бул')] | Найдутся три элемента: "Булочка с корицей", "Булка с маслом", "Булка с маслом + Капучино = 400 руб. вместо 430" |
| Элементы с ценой (содержащие "руб") | находят любые элементы, в тексте которых содержится подстрока "руб" | ❌ | //*[contains(text(), 'руб')] | Все ценники |
| Текст внутри элементов с классом name | извлекает текстовое содержимое из элементов `<span>` с классом "name" | ❌ | //span[@class='name']/text() | Все названия товаров |
| Текст, содержащий слово "скидка" в любом регистре | находит любые элементы, в тексте которых содержится слово "скидка", игнорируя регистр букв | ❌ | //*[contains(translate(text(), 'СКИДКА', 'скидка'), 'скидка')] | Элементы со словом "скидка" |
| Точный текст "Эрл грей с бергамотом" | находят элементы, текстовое содержимое которых точно равно "Эрл грей с бергамотом" | ❌ | //*[text()='Эрл грей с бергамотом'] | Описание английского чая |
| Текст внутри textarea | найдет текст внутри textarea | ❌ | //textarea/text() | Текстовое поле комментария |
| Элементы с длинным описанием (>43 символов) | находят любые элементы, текстовое содержимое которых превышает 43 символа по длине | ❌ | //*[string-length(text()) > 43] | Длинные описания товаров |
| Текст внутри элементов с классом name | извлекает текстовое содержимое из элементов `<span>` с классом "name" | ❌ | //span[@class='name']/text() | Все названия товаров |

🎯 **Обратите внимание на то, что поиск по тексту элемента регистрозависимый -- это значит, что запросы:**

//*[contains(text(), 'булка')] **и** //*[contains(text(), 'Булка')] **приведут к различным результатам**

## 🌳 **3. Движение вниз по дереву (поиск потомков)**

| **Что ищем?** | **Что находит?** | **CSS селектор пример** | **XPath пример** | **Что найдёт в меню в html файле** |
|--------------|----------------|----------------------|----------------|-----------------------------------|
| Непосредственные дети body | находят детей элемента body | body > * | //body/* (краткая форма)<br>//body/child::* | Блок с кнопками, заголовок меню, разделы: булочки, десерты, напитки и т.д. |
| Все прямые дети от body с тегом `<div>` | находят прямых потомков с тегом div, найдет не все секции, так как некоторые вложены | body > div | //body/div (краткая форма)<br>//body/child::div | Разделы: булочки, десерты, напитки и т.д. |
| Абсолютный путь от корня | находят блок h3 | body > div > h3 | //body/div/h3 | "Почему надо выбрать нас", "Контактная информация", "Если у Вас День рождения" |
| Все потомки body любого уровня | находят все элементы внутри body, независимо от уровня вложенности | body * | //body//* (краткая форма)<br>//body/descendant::* | Все элементы внутри body |
| Все непрямые потомки дети с тегом `<div>` от body | находят все элементы div внутри body, независимо от уровня вложенности | body div | //body//div (краткая форма)<br>//body/descendant::div | Все элементы внутри body c div |
| Все span внутри элементов с классом item | находят все элементы `<span>`, которые находятся внутри элементов с классом "item", на любом уровне вложенности | .item span | //*[@class='item']//span | Названия и цены |
| Прямые дети элемента с классом item | находят все непосредственные дочерние элементы внутри элемента с классом "item" | .item > * | //*[@class='item']/* | Названия, цены, описание |
| Все элементы внутри формы заказа | находят все элементы, которые находятся внутри формы с идентификатором "orderForm", на любом уровне вложенности | #orderForm * | //form[@id='orderForm']//* | Все дочерние элементы формы заказа |
| Текстовые узлы внутри body | извлекают все текстовые узлы, находящиеся внутри элемента `<body>` | ❌ | //body//text() | Все элементы с текстовым содержимым |
| Сам body и все его потомки | находят сам элемент `<body>` и все его дочерние элементы, независимо от уровня вложенности | ❌ | //body/descendant-or-self::* | Body + все элементы |
| **Любой потомок** определенного типа | находят все элементы `<span>`, которые являются потомками элемента с идентификатором "buns", на любом уровне вложенности | #buns span | //div[@id='buns']//span | Все span внутри раздела булочек |
| **Прямой потомок** конкретного типа | находят только непосредственные дочерние элементы с классом "item", которые находятся внутри элемента с идентификатором "buns" | #buns > .item | //div[@id='buns']/div[@class='item'] | Только товары в булочках |
| Элементы на **определенном уровне** вложенности | находят элементы, находящиеся ровно на пятом уровне вложенности относительно корня документа `<body>` | ❌ | //body/*/*/*/*/* | Строки: 'Недорого', 'С любовью' |
| **Последний потомок** каждого родителя | находят последний дочерний элемент внутри каждого div с классом "menu-section" | ❌ | //div[@class='menu-section']/*[last()] | Последний элемент в каждой секции |
| Все элементы с тегом `<button>` | корректно находят элементы с именем тега button | button | //button | Кнопки |
| Все элементы (ссылки) с тегом `<a>` | находят элементы с именем тега a. | a | //a | Ссылки на кнопки, на телефон и email |

## ⬆️ **4. Движение вверх по дереву (поиск предков)**

| **Что ищем?** | **Что находит?** | **CSS селектор пример** | **XPath пример** | **Что найдёт в меню в html файле** |
|--------------|----------------|----------------------|----------------|-----------------------------------|
| Родитель элемента | найдет родительские элементы акций | ❌ | //*[@class='promo-item']/.. | Блок "Акции дня" |
| Родитель, если он div | находят родительский элемент, но только если он имеет тег div. | ❌ | //span[@class='name']/parent::div | Позиции в меню |
| Родитель с условием | находят родительский элемент div для `<button>`, но только если этот родитель имеет атрибут data-promo со значением "student" | ❌ | //button/parent::div[@data-promo='student'] | Блок "Студенческая скидка" |
| Все предки цены "150 руб." | находят все элементы-предки (от родителя до корня документа) для элемента `<span>` с текстом "150 руб." | ❌ | //span[text()='150 руб.']/ancestor::* | span → div.item → div#buns → body → html |
| Все div-предки | находят все элементы-предки для span[@class='tag bestseller'], которые имеют тег div | ❌ | //span[@class='tag bestseller']/ancestor::div | "Сдобная булка с изюмом" и Блок "Булочки" |
| Все предки с id | находят все элементы-предки, у которых присутствует атрибут id | ❌ | //span[@class='name']/ancestor::*[@id] | Названия разделов и блоки позиций в меню |
| Ближайший предок | находят ближайший предок любого типа (аналогично выбору родителя ../ или parent::*) | ❌ | //span[@class='tag bestseller']/ancestor::*[1] | "Сдобная булка с изюмом" |
| Сам элемент + предки | находят сам элемент `<span>`, а также все его элементы-предки, до самого корня документа. | ❌ | //span[@class='tag bestseller']/ancestor-or-self::* |  |
| Самый дальний предок | находят самый верхний (самый дальний) элемент-предок для элемента `<span>` | ❌ | //span[@class='tag bestseller']/ancestor::*[last()] |  |
| Родитель кнопки | корректно находят непосредственный родительский элемент для кнопки с атрибутом data-id='promo-2' | ❌ | //button[@data-id='promo-2']/.. | Блок "Студенческая скидка" |
| Предок div с id | находят все элементы-предки с тегом div, у которых также присутствует атрибут id | ❌ | //span[@class='name']/ancestor::div[@id] | Сама блок и товар, которой находится в ней |
| Форма, содержащая input | находят элемент `<form>`, который является предком для поля ввода с именем name. (Обратите внимание, :has — это экспериментальный/новый CSS селектор, который не всегда поддерживается) | form:has(input) | //input[@name='name']/ancestor::form | Форма заказа |
| Родительский div для input с type="checkbox" | находят непосредственный родительский элемент div для поля ввода с типом checkbox | ❌ | //input[@type='checkbox']/parent::div | Блок с чекбоксами |
| Все предки textarea | находят все элементы-предки (от родителя до корня документа) для элемента `<textarea>` | ❌ | //textarea/ancestor::* | textarea → div.form-group → form → div#order-form → body → html |
| Ближайший div-предок с id | находят **ближайший** элемент-предок с тегом div, у которого присутствует атрибут id. | ❌ | //span[@class='name']/ancestor::div[@id][1] | Позиции в меню |
| Форма-предок для кнопки "Отправить" | находят элемент `<form>`, который является **предком** для кнопки с точным текстом "Отправить заказ" | ❌ | //button[text()='Отправить заказ']/ancestor::form | Форма заказа |

## ↔️ **5. Движение вбок по дереву (поиск соседей)**

| **Что ищем?** | **Что находим?** | **CSS селектор пример** | **XPath пример** | **Что найдёт в меню в html файле** |
|--------------|----------------|----------------------|----------------|-----------------------------------|
| Все товары после первого | находят все элементы с классом "item", которые следуют за первым элементом с классом "item". | .item ~ .item | //*[@class='item']/following-sibling::*[contains(@class,'item')] | Все товары кроме первого |
| Следующий сосед h2 | находят **непосредственно** следующий элемент-сосед любого типа, идущий сразу за элементом h2 | h2 + * | //h2/following-sibling::*[1] | Комментарии к секциям |
| Все секции после первой | находят все элементы div с классом "menu-section", которые следуют за элементом с идентификатором "buns" | #buns ~ .menu-section | //*[@id='buns']/following-sibling::*[contains(@class,'menu-section')] | Все секции |
| Все элементы после формы | находят **все** элементы, которые находятся после элемента `<form>` в линейном порядке документа (независимо от уровня вложенности) | ❌ | //form/following::* | "Почему надо выбрать нас", "Контактная информация", "Если у Вас День рождения" |
| Кнопки рядом друг с другом | находят все кнопки с классом "submit-btn ", которые следуют непосредственно за другой кнопкой с тем же классом | .submit-btn + .reset-btn | //button[@class='submit-btn']/following-sibling::button[@class='reset-btn'] | Кнопка "Очистить" |
| Все соседние кнопки в навигации | находят все ссылки в навигации с классом "nav-btn", которые следуют за первой такой ссылкой. | .nav-btn ~ .nav-btn | //*[contains(@class,'nav-btn')][1]/following-sibling::*[contains(@class,'nav-btn')] | Все кнопки навигации кроме первой |
| Предыдущий товар перед special | находят **непосредственно** предыдущий элемент-сосед с классом "item", который расположен прямо перед элементом с классом "special" | ❌ | //div[@id='item-7']/preceding-sibling::div | "Тирамису" и "Чизкейк Нью-Йорк" |
| **Предыдущий сосед** определенного типа | находят непосредственный предыдущий элемент с тегом `<span>`, расположенный перед элементом с классом "special-sib". | ❌ | //div[@id='item-7']/preceding-sibling::div[2] | "Тирамису" |
| **N-й сосед после** текущего | находят второй элемент `<a>`, который следует за элементом с классом со словом "first" | ❌ | //*[contains(@class,'first')]/following-sibling::a[2] | Третий сосед после первого |
| Соседи **с определенным классом** | находят все элементы-соседи, следующие за элементом с классом со словом "first", у которых присутствует класс "special" | .first ~ .special | //*[contains(@class,'first')]/following-sibling::*[contains(@class, 'special')] | "Напитки" |

## 📍 **6. Поиск по позиции элемента**

| **Что ищем?** | **Что находим?** | **CSS селектор пример** | **XPath пример** | **Что найдёт в меню в html файле** |
|--------------|----------------|----------------------|----------------|-----------------------------------|
| Первый дочерний элемент с атрибутом class="item discounted" | находят первый дочерний элемент (или span, в случае XPath) внутри элемента с классом "item discounted". | .item.discounted :first-child | //*[@class='item discounted']/span[1] | "Эклер ванильный" |
| Второй дочерний элемента с атрибутом class="item discounted" | находят второй дочерний элемент (или span) внутри элемента с классом "item discounted". | .item.discounted :nth-child(2) | //*[@class='item discounted']/span[2]<br>или<br>//*[@class='item discounted']/span[position()=2] | "250 руб." |
| Третий дочерний элемент с атрибутом class="item discounted" | находят третий дочерний элемент (или span) внутри элемента с классом "item discounted" | .item.discounted :nth-child(3) | //*[@class='item discounted']/span[3] | "200 руб." |
| Для выбора элементов в диапазоне со 2-го по 5-й включительно | находят с 3 по 5 элементы div с классом "item" в указанном диапазоне позиций. | div.item:nth-of-type(n+3):nth-of-type(-n+5) | //div[contains(@class,'item')][position() >= 3 and position() <= 5] | "Сдобная булка с изюмом", "Круассан шоколадный", "Эклер ванильный", "Горячий шоколад" |

## 🔀 **8. Сравнение CSS Selectors и Xpath**

| **Критерий/Тип** | **CSS Selectors** | **XPath** |
|-----------------|-----------------|----------|
| Основное назначение | Стили + выбор элементов | Поиск в XML/HTML |
| Синтаксис | Простой, компактный | Более сложный, похож на путь (path) |
| Поиск по тексту | Нет | Да, по полному или частичному совпадению) (contains(text(), '...'), text()='...') |
| Функциональность | Более ограниченный набор функций для поиска элементов. Работа псевдоклассов может отличаться в разных браузерах | Богатый набор функций (поиск по позиции, условиям, вычислениям) |
| Навигация | Только вниз (потомки) | Гибко работает с осями элементов. Поиск вверх/вниз/вбок |
| Навигация вверх | ❌ | Найти родителя и взять его деда parent::, ancestor:: |
| Навигация вбок | Только ближайший сосед | Любой по счёту (following-sibling::, preceding-sibling::) |
| Быстродействие | Быстрее в браузерах | Может быть медленнее |
| Простота освоения | Простой для изучения | Сложный в освоении |
| Читаемость | Краткий, читабельный | Может быть громоздким |
| Гибкость | Ограниченна

### Когда использовать CSS:
- Простые селекторы по классу/ID
- Когда важна производительность

### Когда использовать XPath:
- Поиск по тексту содержимого
- Сложная навигация (к родителям, соседям)
- Динамические условия выборки
